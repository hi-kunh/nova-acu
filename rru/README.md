## 검산

문서의 프레임 규칙과 참조 코드는 **문서에 적은 그대로 복사해** 돌려 봅니다.

```
make -C acud rrucheck && ./acud/rru_proto_check
```

CRC 검사값, 메시지별 전체 길이(= 8 + payload), 파서의 네 가지 경우
(정상 / payload에 `STX`·`ETX` 포함 / CRC 훼손 / 깨진 프레임 뒤 회복)를 봅니다.
**문서를 고치면 이 파일도 같이 고쳐** "문서대로 짜면 정말 되는가"를 계속 확인합니다.

## 지금 막혀 있는 것

RRU 개발보드(NUCLEO-C562RE)가 오기 전이라 **실측이 하나도 없습니다.**
설계 초안 10절의 8가지가 RRU 쪽 답을 기다리는 항목입니다 — 특히:

- 이벤트 버퍼 크기 (끊긴 사이 카드 태그를 잃지 않으려면 몇 건까지 들고 있을 수 있는가)
- USB 시리얼 번호를 채울 수 있는가 (여러 대를 구분하는 데 필요)
- VBUS/GND 처리 (RRU가 자체 전원이라 결정이 필요)
